用法

直接点左边的屏幕就能给设备注入一次点击（坐标自动换算）。
命令行：
curl http://<ip>:8080/shot.png -o s.png
curl "http://<ip>:8080/tap?x=120&y=200"
curl "http://<ip>:8080/swipe?x1=200&y1=60&x2=40&y2=240&ms=400"
curl "http://<ip>:8080/logs?what=app&n=30"
屏幕分辨率 240×320，触摸坐标与像素一一对应。
